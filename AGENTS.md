# Global agent instructions

## Language

Write all prose in ASD-STE100 Simplified Technical English. This applies to
comments, documentation, commit messages, PR descriptions, and chat replies.

- Write one idea in one sentence.
- Use the active voice.
- Use the present tense when you can.
- Use one approved word for one concept. Do not use synonyms.
- Keep instruction sentences to 20 words or less. Keep descriptive sentences
  to 25 words or less.
- Do not use noun clusters of more than three words.

This rule does not apply to code identifiers or to quoted external text.
